# Documentation: start here

**Orbitra Assist** is an AI assistant that answers questions from company documents
**without ever showing anyone information they aren't allowed to see**. It runs entirely on
your own computer, for free.

These guides assume **no technical knowledge**. Each one explains its ideas with real
examples from the project.
